# 十五分之一（Fifteen-to-One）

给一个概念十五分钟，再用一分钟把它讲明白。

一个纯前端、无构建步骤的渐进式学习应用（PWA 风格静态站点）：为概念建立卡组、按间隔重复抽取、专注输入十五分钟、录音输出一分钟、沉淀成学习档案，数据全部保存在浏览器本地。

**在线体验**：[https://luoqianyi.github.io/one-fifteenth/](https://luoqianyi.github.io/one-fifteenth/)

## 学习方法

- **十五分钟输入**：专注收集与理解一个概念，不受干扰地沉浸式学习。
- **一分钟输出**：用自己的话讲一遍，录下复盘录音——输出才是内化的开始。
- **间隔重复**：抽取时综合新鲜度、掌握程度与复习间隔，让该复习的概念适时出现。

## 功能

- **抽取（抽卡）**：随机滚动式的加权抽取动画，按间隔重复调度从卡组中抽出今天该学的概念。
- **专注（计时器）**：双阶段计时器（输入 15 分钟 → 输出 1 分钟），支持暂停 / 跳过 / 退出，切换阶段有提示音与浏览器通知。
- **复盘录音**：输出阶段可直接用麦克风录音，学习完成后随会话保存，可在档案中回看。
- **领域（词库）**：领域 / 类目 / 关键词三级词库管理，手动添加或通过 OpenAI 兼容接口获取 AI 候选。
- **档案（学习历史）**：按关键词聚合每次学习会话，统计累计学习次数、投入时长、平均熟练度与已掌握概念，支持展开查看单次详情与复盘录音。
- **数据与备份**：一键导出 JSON 备份，或从备份文件完整恢复（领域、关键词、学习记录、偏好）。

## 技术栈

原生 ES Modules + IndexedDB + localStorage + sessionStorage，无框架、无构建步骤。

| 模块 | 说明 |
| --- | --- |
| `scripts/core/` | 间隔重复调度（`scheduler.js`）、双阶段计时（`timer.js`）、AI 候选（`ai.js`） |
| `scripts/services/` | 偏好存储（`preferences.js`）、数据备份（`backup.js`） |
| `scripts/views/` | 抽取 / 专注 / 领域 / 档案 / 设置 五个页面视图 |
| `styles/` | CSS 变量主题 + 布局 / 组件 / 响应式分文件 |
| `tests/` | 单元测试（`node --test`）与 Playwright 端到端测试 |

## 本地运行

```bash
npm install
npm run serve   # 打开 http://127.0.0.1:4173
```

## 测试

```bash
npm test          # 单元测试
npm run test:e2e  # Playwright 端到端（桌面 + 移动）
npm run test:all  # 全部
```

## 数据说明

所有数据（领域、关键词、学习记录、复盘录音、偏好设置）都只保存在当前浏览器中，不会上传到任何服务器。更换设备或清理浏览器数据前，请先在「设置 → 数据与备份」导出 JSON 备份。

## 部署

纯静态站点，可部署到 GitHub Pages / Vercel / Netlify / Cloudflare Pages 等任意静态托管。当前托管于 GitHub Pages（`main` 分支根目录，已添加 `.nojekyll`）。
