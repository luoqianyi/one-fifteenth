十五分之一——输入输出学习工具设计规格
日期：2026-08-05
状态：已确认

1. 产品目标

“十五分之一”是一款纯前端输入输出学习工具。用户可以创建多个学习领域，在领域内维护任意数量的类目和关键词，并通过随机抽卡、15 分钟自主学习、1 分钟口头讲述、录音与文字复盘形成学习闭环。

项目仅使用 HTML、CSS 和原生 JavaScript，不依赖后端、前端框架或构建流程，可直接部署到 GitHub Pages。

2. 主要约束

- 支持多个学习领域，每个领域包含任意数量类目。
- 关键词可手动维护，也可通过 OpenAI 兼容接口生成建议。
- API 配置包括 API Key、Base URL 和模型名。
- API Key 仅保存在当前浏览器；界面必须明确说明静态网站无法隐藏 Key。
- 抽卡次数不限，采用间隔重复权重，不永久排除已学关键词。
- 计时阶段可暂停、恢复、重置和自由切换。
- 刷新、休眠或切到后台后，计时器按真实时间恢复。
- 演讲阶段支持浏览器本地录音、文字复盘和掌握度评分。
- 数据保存在浏览器中，并支持 JSON 导入导出；API Key 默认不导出。
- 视觉采用纸张与索引卡风格，不使用紫色渐变、纯平背景或 Emoji 图标。

3. 技术架构

采用模块化单页应用：

- index.html：应用外壳、语义化页面结构与视图容器。
- styles/：基础变量、布局、组件、响应式和动效样式。
- scripts/：按职责拆分的数据访问、状态管理、AI、抽卡、计时、录音、导入导出和界面模块。
- assets/：必要的静态图形和声音资源；界面图标优先使用内嵌 SVG。

应用通过原生 ES Modules 组织代码，不使用打包器。所有资源使用相对路径，确保部署在 GitHub Pages 仓库子路径下仍能加载。

4. 页面结构

4.1 今日抽卡

- 可选择一个学习领域或从全部领域抽取。
- 首页突出一张大型索引卡和主要抽卡按钮。
- 卡片展示关键词、所属领域、类目、难度和一句简介。
- 支持翻卡、跳过、开始训练和手动选择关键词。
- 不限制每日抽卡次数。

4.2 专注训练

- 包含 15 分钟学习阶段和 1 分钟演讲阶段。
- 用户可随时在两个阶段之间切换。
- 支持开始、暂停、恢复和重置。
- 倒计时归零后播放提示音；用户授权后发送浏览器通知。
- 活动计时器在其他视图中以悬浮小条持续显示。
- 演讲阶段可开始和停止麦克风录音。
- 训练结束后填写演讲要点、个人理解和掌握度评分。

4.3 领域管理

- 创建、重命名和删除学习领域。
- 在领域内创建、重命名和删除类目。
- 手动新增、编辑和删除关键词。
- 输入类目后调用 AI 生成建议。
- AI 候选按“入门、进阶、综合”分组，每项包含关键词和一句简介。
- 用户可勾选、编辑并批量加入；加入前去除已有重复词。

4.4 学习档案

- 按日期查看训练历史。
- 查看关键词训练次数、最近学习时间、掌握度和文字复盘。
- 播放或删除本地录音。
- 支持按领域、类目和日期筛选。

4.5 设置与数据

- 配置 API Key、Base URL 和模型名。
- 提供 API 连通性测试。
- 配置提示音和浏览器通知。
- 导出完整学习备份，默认排除 API Key。
- 导入时支持“合并”和“覆盖”两种模式，并在写入前确认。
- 提供清空学习数据操作，执行前二次确认。

5. 数据模型与存储

5.1 localStorage

保存轻量配置：

- 当前视图和活动领域。
- AI 接口配置。
- 声音与通知偏好。
- 当前计时器阶段、状态、剩余时间和目标结束时间。
- 当前未提交训练草稿的标识。

5.2 IndexedDB

保存结构化及二进制数据：

- domains：学习领域。
- categories：领域下的类目。
- keywords：关键词、难度、简介和复习统计。
- sessions：抽卡与训练记录、复盘和掌握度。
- recordings：录音 Blob 与关联训练记录。

5.3 关系边界

- 类目必须归属于一个领域。
- 关键词必须归属于一个类目。
- 训练记录必须关联一个关键词，并保存训练当时的关键词、类目和领域快照，防止后续重命名破坏历史展示。
- 删除领域或类目前必须展示受影响的关键词与历史数量；确认后级联删除当前词库数据，历史训练快照仍保留，相关录音由用户选择保留或删除。

6. AI 建议流程

1. 用户选择领域、输入类目名称和建议数量。
2. 客户端向配置的 OpenAI 兼容 chat completions 端点发送请求。
3. 提示模型只返回严格 JSON，数据包含 name、level 和 summary。
4. 客户端清理可能存在的代码围栏并解析 JSON。
5. 校验字段、允许值和文本长度，丢弃无效项。
6. 按领域与类目内的标准化关键词名称去重。
7. 将候选清单分组展示，用户勾选和编辑后批量写入。

若浏览器因 CORS 无法调用接口，应明确提示“该接口不允许浏览器跨域直连”，并建议更换允许浏览器访问的兼容接口。请求失败、超时或格式错误不得写入部分数据，用户已填写的内容必须保留。

7. 抽卡算法

每个可用关键词计算动态权重：

- 从未训练的关键词获得最高基础权重。
- 距上次训练时间越久，权重越高。
- 掌握度越低，权重越高。
- 最近连续出现的关键词获得短期惩罚，避免重复轰炸。
- 用户跳过的关键词只做轻微短期降权，不视为完成学习。

从所有正权重关键词中进行加权随机抽取。若当前筛选范围没有关键词，界面引导用户进入领域管理，而不是显示空白卡片。

8. 计时与录音

计时器保存阶段、运行状态、剩余毫秒数和目标结束时间。运行中以目标结束时间减去当前时间计算剩余时间；暂停时固化剩余时间。页面加载、visibilitychange 和 focus 时重新校准。

录音使用 MediaRecorder：

- 仅在用户主动点击后申请麦克风权限。
- 录音过程中显示时长和录音状态。
- 停止后允许试听、重录或保存。
- 麦克风被拒绝、设备缺失或浏览器不支持时，降级为纯文字复盘。
- 不向 AI 接口或任何服务器上传录音。

9. 导入导出

备份格式包含 schemaVersion、exportedAt、领域、类目、关键词、训练记录及录音。录音以带 MIME 类型的可恢复编码写入 JSON，因此大型备份可能体积较大；导出前显示预计大小。

导入步骤：

1. 读取文件并校验 JSON。
2. 校验 schemaVersion 和必要字段。
3. 展示领域、关键词、记录及录音数量摘要。
4. 用户选择合并或覆盖并确认。
5. 在单次事务边界内写入；失败时不得留下半导入状态。

API Key 默认且始终不包含在普通备份中。

10. 视觉设计

- 暖米白背景，加入极轻微纸张纤维纹理。
- 深墨色正文，暖橙色用于主按钮、计时和选中状态。
- 鼠尾草绿表示较高掌握度，暗红色用于警告。
- 卡片使用细边框、克制阴影和纸张层次。
- 桌面端使用左侧书签式导航；移动端使用底部导航。
- 抽卡使用克制的翻面动画，计时器使用圆环，录音使用波纹反馈。
- 支持 prefers-reduced-motion，减少或关闭非必要动画。
- 使用 SVG 图标，不使用 Emoji。
- 关键交互满足键盘操作，并提供清晰焦点样式和可读标签。

11. 异常处理

- AI 请求失败：显示可操作的错误并允许原参数重试。
- AI 格式异常：尝试提取 JSON；仍失败则终止导入候选。
- CORS 异常：给出专项提示。
- 麦克风不可用：允许跳过录音。
- 本地存储空间不足：提示删除旧录音或先导出备份。
- 导入文件损坏或版本不兼容：校验阶段拦截。
- 存在未保存复盘时离开页面：触发离开提示。
- 删除与覆盖操作：必须二次确认。

12. 首次使用流程

首次进入显示简洁引导：

配置 AI → 创建领域 → 添加类目 → 获取 AI 建议 → 勾选关键词 → 开始抽卡。

用户也可以跳过 AI 配置，完全手动录入关键词。

13. 验收标准

- 可创建多个领域、任意数量类目和关键词，刷新后数据完整。
- OpenAI 兼容接口配置、测试、建议生成、校验、去重与批量加入有效。
- 抽卡采用加权随机，未学习词优先且不会长期重复同一词。
- 两阶段计时支持暂停、恢复、重置、切换和刷新后恢复。
- 录音可录制、试听、重录、保存、回放和删除；无权限时可继续训练。
- 可保存文字复盘、掌握度，并在学习档案中筛选查看。
- JSON 可完整导出和恢复；损坏文件被拦截；API Key 不被导出。
- 桌面与移动端均可完成全部核心流程。
- GitHub Pages 仓库子路径下资源加载正常。
- 发布后必须在真实 Pages 地址完成一次端到端浏览器验收。

14. 发布目标

项目仓库默认命名为 fifteen-to-one，使用 GitHub Pages 从默认分支根目录发布。实际仓库名和公开范围在执行外部发布前由用户最终确认。
